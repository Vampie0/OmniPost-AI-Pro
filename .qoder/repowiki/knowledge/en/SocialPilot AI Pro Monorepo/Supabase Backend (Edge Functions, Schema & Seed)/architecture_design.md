The module is a standard Supabase project layout. `migrations/20240001000000_initial_schema.sql` defines the entire database: enums (`user_role`, `subscription_tier`, `post_status`, `platform_type`), tables (`app_config`, `ai_config`, `profiles`, `folders`, `posts`, `templates`, `generated_images`, `analytics`, `notifications`, `admin_logs`), Row Level Security policies gated by a `public.is_admin()` helper function, a trigger that auto-creates profiles on auth user signup, and Realtime publication of selected tables. `seed.sql` inserts default white-label branding, AI provider defaults, and starter templates. `functions/generate-content/index.ts` and `functions/generate-image/index.ts` are Deno-based Edge Functions that authenticate via Supabase Auth, read runtime config from `ai_config`, call external LLM/image APIs (Google Gemini or Replicate SDXL) using environment secrets (`GEMINI_API_KEY`, `REPLICATE_API_TOKEN`), persist results, and debit credits through the `decrement_user_credits` RPC. Both functions share an identical request pattern: CORS preflight handling, Supabase client construction with per-request Authorization header propagation, JSON body validation, and uniform error responses. `config.toml` is present as the Supabase CLI entry point but currently empty.
