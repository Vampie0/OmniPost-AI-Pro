The root defines a pnpm workspace (`apps/*`, `packages/*`) with Turborepo as the task runner: `turbo.json` declares shared `build`, `lint`, `dev`, and `clean` tasks that depend on upstream package builds (`^build`, `^lint`) and cache `.next`/`dist` outputs. All TypeScript projects inherit strict compiler options from the root `tsconfig.base.json`. The Supabase backend (Edge Functions, schema, seed) is treated as a sibling workspace alongside the frontend apps, so the same monorepo tooling coordinates development across client, serverless functions, and database provisioning scripts.
